# Возрождение цивилизации — пакет заданий для Codex / Claude Code

Это **документы для разработки**, а не готовый исходный код игры. Цель — локальная одиночная браузерная игра: Go-симулятор, небольшой локальный Go HTTP-сервер, React + TypeScript (Vite), SQLite для сохранений, Python только для анализа симуляций. Публичный backend, аккаунты, хостинг и мультиплеер **не нужны**.

## Как работать с пакетом

1. Создать **пустой Git-репозиторий** и открыть его в GoLand. Скопировать **весь этот пакет** в корень репозитория (корневые `AGENTS.md`, `README_START_HERE.md`, каталог `docs/`).
2. Сохранить стартовый коммит с документацией: `git init`, `git add .`, `git commit -m "docs: initial game specification"` (при необходимости сначала настроить имя/email Git).
3. Открыть Codex в GoLand или терминале. **Первое сообщение взять из `docs/08_CODEX_TASKS.md`, задача 0**.
4. Давать **по одной задаче**, не отправлять весь план на реализацию сразу. После каждой стадии запускать тесты, смотреть изменения через Git Diff, делать коммит.
5. Если агент предлагает усложнение, свериться с `docs/CONCEPT.md` и `docs/09_DECISIONS.md`; не добавлять фичу «на всякий случай».
6. Если меняется игровое правило, сначала обновить соответствующие MD, затем код и тесты.

## Границы первой версии

- **Один игрок, один локальный процесс, один браузер**; сервер только на `127.0.0.1`.
- Рабочий браузерный вертикальный срез требуется **раньше**, чем полная симуляция: интерфейс должен появиться уже после базового движка.
- Не обязательно в первом запуске иметь все технологии, карту, культурные ветки и сотни событий. Развивать игру по этапам.
- Все случайные числа при симуляции идут из одного воспроизводимого источника с seed; события и игровой мир не генерируются через LLM во время игры.
- Числа баланса — **черновые конфигурации**, а не согласованные параметры. Настраивать после массовых прогонов.

## Цель «готово»

В браузере на локальном компьютере можно создать игру с seed, наблюдать непрерывное течение времени, пробудить людей, задать приоритеты, читать разнообразную ленту событий, открыть дерево технологий и карту, сохранить/загрузить партию и получить итог после смерти героя. Те же правила доступны для автоматического запуска тысяч партий без UI.
