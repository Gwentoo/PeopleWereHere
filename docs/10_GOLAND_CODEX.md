# 10 — Codex в GoLand на Windows (справка, ноябрь 2026)

## Вариант А. Встроенная интеграция GoLand (рекомендуется)

1. Обновить GoLand и включить/установить плагин **JetBrains AI Assistant**: `Settings → Plugins`.
2. Открыть окно **AI Chat**, выбрать агента **Codex**.
3. Отправить короткое сообщение для запуска активации; выбрать **Install and Continue**.
4. В способах входа выбрать **ChatGPT** или **ChatGPT (device code)** и авторизоваться в своём аккаунте ChatGPT.
5. В режимах доступа для разработки выбрать **Workspace access**, а не Full access. Codex сможет изменять файлы репозитория и попросит подтверждение для других операций.
6. Открыть `AGENTS.md` и `docs/08_CODEX_TASKS.md`, отправить **задачу 0**, проверить diff после работы.
7. Активный файл/выделение IDE могут передаваться в контекст; **прочие документы нужно явно указывать через `@` или именами файлов**. Постоянные инструкции Codex читает из корневого `AGENTS.md`.

Вход через аккаунт ChatGPT **отличается от использования отдельного OpenAI API key**. Он позволяет применять поддерживаемые лимиты своего плана; возможные ограничения смотрите в UI.

Официальные страницы:
- https://www.jetbrains.com/help/ai-assistant/codex-agent.html
- https://www.jetbrains.com/help/ai-assistant/activate-agents.html
- https://learn.chatgpt.com/docs/codex/ide

## Вариант Б. Codex CLI в терминале GoLand

1. Установить Codex по официальной инструкции для Windows. В PowerShell (после проверки источника):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

Альтернатива при установленном Node/npm:

```powershell
npm install -g @openai/codex
```

2. Перезапустить терминал, проверить `codex --version`.
3. Открыть корень проекта в GoLand, открыть вкладку **Terminal** и выполнить `codex`.
4. Войти через **Sign in with ChatGPT**, выбрать режим с ограниченным доступом к рабочей папке.
5. Скопировать задачу 0 из `docs/08_CODEX_TASKS.md`. Codex видит файлы текущей рабочей папки и может изменять репозиторий; наблюдать изменения в GoLand через Git Diff.

Официальный репозиторий: https://github.com/openai/codex

## Дополнительно: доступ Codex CLI к инструментам GoLand

Начиная с поддерживаемых версий GoLand, IDE умеет отдавать внешнему Codex инструменты через **MCP Server**. Это *не обязательная настройка* для редактирования файлов — Codex CLI и без неё видит файлы проекта.

Если нужна интеграция с анализом/сборкой IDE: `Settings → AI → MCP Server` → включить сервер → `Clients Auto-Configuration` → Auto-Configure для Codex → перезапустить клиент. Просмотреть список предоставляемых инструментов и права доступа.

Официальная инструкция: https://www.jetbrains.com/help/go/mcp-server.html

## Безопасная работа

- Первые задачи выполнять с ограничением на текущую рабочую папку.
- Делать коммит перед каждой стадией; проверять diff и тесты перед коммитом.
- Не выбирать Full access без необходимости. Не разрешать удаление произвольных каталогов.
- Если интеграции JetBrains нет в вашей версии IDE, использовать CLI во встроенном терминале, а не устанавливать неизвестные неофициальные «Codex plugins».
